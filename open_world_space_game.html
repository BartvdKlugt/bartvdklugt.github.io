Een game die ik heb gemaakt!

De naam is eX: Beyond the Stars.

Programma:
Genre: Adventure
Thema: Game Development
Jaar: 2025

Een screenshot waar de speler in een ruimteschip vliegt.

Dit project is een open world space game genaamd eX: Beyond the Stars.
In deze game vlieg je met een ruimteschip naar een andere planeet.
Op die planeet doe je een quest. Je moet de code vinden op een deur te openen naar een schatkist.
Als je daar klaar mee bent, dan kan je terug vliegen naar de ruimte.
Sommige assets komen van sites zoals Sketchfab of Free3D.
Ik heb zelf ook assets gemaakt, zoals bijvoorbeeld de planeten en de space base.
