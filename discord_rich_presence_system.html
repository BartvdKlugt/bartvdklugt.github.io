Discord Rich Presence Systeem🎮

Een script die je Discord rich presence kan aanpassen!

Voor als de game die je speelt geen rich presence functie hebt.

Programma:
Programmeertaal:
Thema: Games
Jaar: 2025

Discord die Zelda als mijn rich presence laat zien.

Dit project gaat over een Discord rich presence systeem. Dit project is geprogrammeerd in de programmeertaal Python.
Wanneer je het script opent, vraagt hij je om een nummer te selecteren van de game die je speelt, en als je dat nummer doorgeeft, vranderd het script je rich presence naar die game.

Het script leest de volgende informatie uit een JSON bestand:
• Game icoon
• Game titel
• Welk platform je op speelt
• Je profielfoto in die game
• Je IGN

Je moet dit allemaal wel zelf invullen per game. En de afbeeldingen wordt ingeladen via een link.
